**DANFO RUSH** — drive a yellow Lagos danfo through traffic, pull into bus stops to pick up passengers for ₦ fares, and hit your daily fare target before sunset. Dodge cars, okadas and potholes, refuel at blue FUEL bays, chain pickups for combos, and survive ever-busier days. A complete original 2D canvas arcade game built for make.fun's best-game-01 bounty: title screen, full HUD, day-complete and game-over screens with restart, procedural art and WebAudio sound, zero network requests.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome — or serve `game/` with any static file server and open `game/index.html`. Controls: ← → steer, ↑ ↓ speed, SPACE horn, P pause, R restart, M mute.
